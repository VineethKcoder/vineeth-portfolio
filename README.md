# Vineeth K — Applied AI Engineering Portfolio

Static portfolio covering voice agents, RAG, Python APIs and machine learning.

## Run locally

Run `python -m http.server 8080 --bind 127.0.0.1` and open http://127.0.0.1:8080. No build or dependencies are required.

## Content

- index.html: projects, experience, skills and contact
- styles.css: responsive styles
- script.js: footer year
- resume.pdf: current downloadable résumé
- assets/vistara-demo.mp4: configuration and local backend walkthrough
- assets/vistara-cover.jpg: video cover

The silent Vistara walkthrough uses fictional data. It shows configuration and local API tests rather than a live voice call. The tunnel address is masked. Employer projects are described without sharing their code.

## Hosting

Deploy as a static site. For GitHub Pages, configure main from / (root), if supported for the account and repository visibility. Historical URL: https://vineethkcoder.github.io/vineeth-portfolio/ . Verify deployment before sharing with recruiters.
